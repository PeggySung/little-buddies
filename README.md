# 小夥伴粗企玩 · LITTLE BUDDIES

專為小夥伴們打造的旅遊 app，從一個人到一群人，國內國外都能用。
前身是我們沖繩之旅的行程 app，現在改成任何國家、任何行程都能規劃的通用版。

👉 **https://peggysung.github.io/little-buddies/**

## 功能

- 🗺️ **行程**：建立旅程、每日行程、交通與住宿
- ✅ **行前準備**：準備清單
- 💰 **記帳分帳**：記錄花費、旅程結束一鍵結算
- 🌤️ **天氣**：天氣、日出日落、潮汐（天氣動態背景可在設定裡自己開關）
- 👣 **足跡**：記錄每個人去過的地方
- 🌙 淺色 / 深色模式
- 📴 離線也能看（PWA，可加到手機主畫面）

## 技術

- 純前端 HTML / CSS / JavaScript，部署在 GitHub Pages
- Firebase（Authentication + Firestore）
- Service Worker 離線快取

## 使用說明

app 只開放小夥伴使用：核心成員可以建立旅程並邀請旅伴，旅伴需被邀請才能加入。
